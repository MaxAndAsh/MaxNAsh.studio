MAX'N'ASH WEBSITE STARTER
Files:
- index.html: complete responsive website page
- script.js: interactions, current year, contact form email draft
- logo.png: supplied Max'N'Ash character logo
- website-leaflet.png: visual mockup/leaflet preview

To preview: open index.html in a browser.
To publish with GitHub Pages: upload all four files/folders' contents to the root of your repository, commit, then open Settings > Pages and choose Deploy from a branch, main, /(root).
The contact form opens the visitor's email app; it does not send automatically. For automatic form delivery, connect a form backend/service first.
Replace the YouTube channel link if your channel URL changes. Add audio/video embeds in index.html when ready.
