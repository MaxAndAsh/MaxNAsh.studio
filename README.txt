CUBEVERSE: ELEMENTAL WORLDS — PROTOTYPE 0.1

Included:
- Responsive browser-based prototype for phones and computers
- Username validation (local demo only)
- Character selection: Custom hero, Max (fire), Ash (lightning), Cosmic Jarvis
- Eight selectable elements with sample abilities
- Simple gathering, exploration, combat, XP, health and levels
- Local browser save using localStorage
- Demo multiplayer-code UI (not connected to real online servers)
- No email, phone number, real name, or address requested

IMPORTANT LIMITATION:
This is an early playable prototype, not a complete 3D voxel game. Worldwide online multiplayer is NOT active. The "create code" and "join code" controls are demos only. Real multiplayer requires a separately deployed backend/server, networking, moderation, testing, and hosting. GitHub Pages can host the front-end but not run the game server.

HOW TO PLAY:
1. Open index.html in a modern browser.
2. Enter a username with 3–16 letters, numbers, or underscores.
3. Choose a character and outfit, then tap Apply character.
4. Select any element. Max starts with fire; Ash starts with lightning. Powers can be switched.
5. Gather wood, find crystals, fight creatures, explore zones, use abilities, and save progress.

PUBLISH ON GITHUB PAGES:
1. Create or open a GitHub repository.
2. Upload index.html (and this README if you want).
3. In repository Settings > Pages, choose Deploy from a branch.
4. Select the main branch and /(root), then Save.
5. Wait for GitHub Pages to publish the site.
